# Animus-Mod-Manager---Assassin-s-Creed-Black-Flag-Resynced
Enjoy a Mod Organizer 2 like experience with Animus Mod Manager which is a dedicated light weight manager for Assassin’s Creed Black Flag Resynced, designed to keep gameplay mods, outfits, weapons and crew re textures organized in one place with simple enable/disable controls, updates and outfit slot management.
