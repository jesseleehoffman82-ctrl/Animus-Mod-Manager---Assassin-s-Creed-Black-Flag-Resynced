ANIMUS MOD & OUTFIT MANAGER 0.1.7 BETA - DEVELOPMENT NOTES
============================================================

Animus Mod & Outfit Manager was created through a human-directed, AI-assisted software
development process. The project owner defined the product requirements,
interface design, installation behavior, supported game content, testing cases,
and release goals.

Early Python backend prototypes were produced with assistance from DeepSeek.
The application was subsequently developed and revised through iterative coding
sessions using OpenAI coding assistance. This later work included the native C#
desktop host, the HTML/CSS/JavaScript interface, backend corrections, archive
compatibility, outfit-slot conflict handling, deployment recovery, regression
tests, .NET 10 migration, and public packaging. The project owner performed
hands-on installation and in-game testing throughout development.

APPLICATION ARCHITECTURE
------------------------

- C# / .NET 10 Windows Forms provides the native Windows application host,
  startup splash screen, window management, and WebView2 integration.
- Microsoft Edge WebView2 renders the local HTML/CSS/JavaScript interface.
- Python 3.14 implements archive analysis, managed mod deployment, backup and
  restoration, outfit/weapon/crew/sail texture handling, metadata, and local RPC.
- Official 7-Zip and DirectXTex utilities provide archive extraction and
  supported texture conversion operations.

The interface is loaded from local files. Direct Nexus downloading is not
enabled in this beta. The manager patches and restores selected game files on
disk and does not inject code into the running game process.

SOURCE AND VERIFICATION
-----------------------

This source archive contains the authored C#, Python, HTML, CSS, and JavaScript
files corresponding to version 0.1.7 Beta, along with regression tests and
BUILD-INSTRUCTIONS.txt. Official redistributable runtimes and third-party
compiled utilities are intentionally excluded from the source-only archive.

The public application archive is built as a framework-dependent .NET 10 x64
application. Users require Microsoft .NET 10 Desktop Runtime x64.
