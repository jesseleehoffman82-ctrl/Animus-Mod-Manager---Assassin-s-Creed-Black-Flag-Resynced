ANIMUS MOD & OUTFIT MANAGER 0.1.5 BETA - SOURCE CODE
============================================================

The complete source corresponding to this release is provided as a separate
file on the Animus Mod & Outfit Manager Nexus Mods page:

https://www.nexusmods.com/assassinscreedblackflagresynced/mods/458?tab=files

Source filename:
Animus-Mod-Manager-0.1.5-Source.zip

The source archive contains the C# desktop host, Python backend, HTML/CSS/
JavaScript interface, regression tests, third-party notices, and complete
build instructions. It contains no compiled executables, DLLs, or nested
archives.

Native host build requirement:
Microsoft .NET 10 SDK x64

Native host build command:
dotnet publish desktop/AnimusModManager.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=false -p:DebugType=None -p:DebugSymbols=false -o build

Animus Mod & Outfit Manager patches and restores selected game files on disk. It does
not inject code into the running game process.

Public application SHA-256 values are published beside each release archive.
